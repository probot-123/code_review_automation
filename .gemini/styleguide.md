### Python Style Rules
- **Indentation**: 5 spaces (not tabs)
- **Imports**:
  - Grouped as: standard lib → third party → local
  - Absolute imports required
- **Type Hints**: Mandatory for public APIs
### Java Style Rules  
- **Brace Style**: K&R (opening brace on same line)
- **Annotations**: 
  - @Override always required
  - @Nullable/@NonNull annotations for parameters
### JavaScript Style Rules
- **Semicolons**: Required for all statements
- **Arrow Functions**: Preferred over function expressions
- **Async/Await**: Required instead of promise chains
